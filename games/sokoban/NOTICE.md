# Sokoban level attribution

This game includes the first 24 puzzles from the classic **Microban** level
collection by **David W. Skinner**.

Source:
https://raw.githubusercontent.com/omerkel/sokoban/master/3rdParty/Levels/Microban.txt

The source level file identifies the collection as “Microban (155 puzzles,
revised April, 2000)” and describes it as a small, concept-focused set for
beginners and experienced players.
